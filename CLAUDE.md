# Вопросы — интервью в свадебный день

Отдельный продукт; от «Свайпа музыки» (~/Claude Music) и монтажа в Resolve (~/Claude Davinci) не зависит. Устройство — в README.md.

- Пользователь — свадебный видеограф, сам задаёт вопросы на свадьбах. Общаться по-русски.
- Любит тёмный кинематографичный интерфейс (графит, слоновая кость, золото).
- Главное требование: работает на площадке без интернета и без Mac — только статические файлы, никакого сервера.
- Вопросы должны давать ответы, пригодные для монтажа: полные фразы, конкретные моменты, роли в фильме (темы в ROLES).
- Проверять в браузере в размере 375×812. После правок поднимать VERSION в docs/sw.js.
- Планы на потом: персональные вопросы по анкете пары; поиск ответов по времени «★» на синхронизированном материале в Resolve.

  личных данных пар в репозиторий не класть). После заметной правки — коммит по-русски и `git push`, отдельно не спрашивать.
