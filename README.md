# Вопросы — интервью в свадебный день

Самостоятельное приложение-шпаргалка для видеографа: карточки с вопросами к паре, гостям и родителям,
разложенные по частям свадебного дня. Работает на телефоне без интернета (PWA), данные хранятся в самом телефоне.

- `app/questions.js` — банк вопросов (формат описан в начале файла). Править вопросы — только здесь.
- `app/app.js` — логика: части дня, колода, отметки «Задан» и «★ Сильный ответ» со временем до секунды,
  журнал с выгрузкой CSV, «Мои вопросы» и свои вопросы (живут между свадьбами), тёмный режим, экран не гаснет.
- `app/sw.js` — офлайн-кэш. **После любой правки файлов в app/ поднять `VERSION`**, иначе телефон покажет старое.
- `Анкета для пары.md` — анкета, которую пара заполняет до свадьбы.

Локально: `python3 -m http.server 8790 --directory app` → http://localhost:8790
Офлайн-режим на телефоне работает только по HTTPS (нужен хостинг, например GitHub Pages).
